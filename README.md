

# Google-Maps-기반 음식점 메뉴 데이터 수집 및 정형화 시스템

> 음식 랜덤 추천 서비스를 위한 데이터 생성 파이프라인

---

# 프로젝트 목표

사용자가 입력한 지역 주변의 음식점과 메뉴 정보를 수집하여

* 정형 데이터로 변환
* Excel 파일 생성
* 추후 음식 랜덤 추천 서비스의 데이터로 활용하는 것

---

# 현재 범위 (v1)

### 포함

✅ 지역 기반 음식점 검색

✅ 음식점 메뉴 정보 수집

✅ 데이터 정제

✅ Excel 저장

---

### 제외

❌ 리뷰 분석

❌ AI 메뉴 분류

❌ 추천 알고리즘

❌ DB 구축

❌ 웹 배포

❌ 사용자 로그인

❌ 즐겨찾기

---

# 전체 흐름

```text
사용자 입력
    ↓
지역 검색
    ↓
Google Maps API
    ↓
음식점 목록 수집
    ↓
음식점 상세 정보 조회
    ↓
메뉴 정보 추출
    ↓
데이터 정제
    ↓
Excel 생성
```

---

# 입력

예시

```text
안산시 상록구
```

또는

```text
한양대학교 ERICA 주변
```

# 수집 데이터

## 음식점 정보

| 필드              | 설명   |
| --------------- | ---- |
| restaurant_name | 음식점명 |
| address         | 주소   |
| category        | 업종   |
| rating          | 평점   |

---

## 메뉴 정보

| 필드              | 설명   |
| --------------- | ---- |
| restaurant_name | 음식점명 |
| menu_name       | 메뉴명  |

# 기능 단계

## Phase 1

음식점 검색

입력

```text
안산시 상록구
```

출력

```text
교촌치킨 안산점
BBQ 안산점
홍콩반점 안산점
```

### 완료 기준

음식점 목록을 가져온다.

---

## Phase 2

메뉴 수집

출력

```text
교촌치킨 안산점
 ├ 허니콤보
 ├ 레드콤보

BBQ 안산점
 ├ 황금올리브
 ├ 자메이카통다리
```

### 완료 기준

메뉴 목록을 가져온다.

---

## Phase 3

데이터 정제

예시

```text
허니콤보
허니 콤보
허니콤보 치킨
```

↓

```text
허니콤보
```

### 완료 기준

중복 제거

빈 값 제거

특수문자 정리

---

## Phase 4

Excel 저장

생성

```text
restaurants_menu.xlsx
```

### 완료 기준

파일 다운로드 가능
